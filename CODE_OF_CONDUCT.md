# Code of Conduct

Fluid Reader should be a useful and safe project for everyone.

## Expected Behavior

- Be kind and direct.
- Use simple words when possible.
- Respect different skill levels, backgrounds, and time zones.
- Give useful feedback about the work, not personal attacks.
- Keep private data out of issues, pull requests, and discussions.

## Not Allowed

- Harassment, threats, or hate speech
- Sexual or violent comments
- Sharing another person's private data
- Posting API keys, selected text, screenshots, clipboard contents, or private documents
- Repeated spam or off-topic comments

## Reporting

If you see a problem, contact the maintainer.

For security or privacy problems, read [SECURITY.md](SECURITY.md) first. Do not post secrets or private data in public.

## Enforcement

The maintainer may edit, hide, or delete comments. The maintainer may block people who keep breaking these rules.
