# Support

Use this page before opening an issue.

## Quick Help

1. Read [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Open Fluid Reader.
3. Open `Commands`.
4. Run `Copy Troubleshooting Guide`.
5. Follow the copied steps.

## Bugs

Use the bug report template.

In Fluid Reader, open `Commands` and run `Copy Issue Bundle`.

Paste that bundle into the issue. It includes support info and safe recent app events.

Do not paste API keys, selected text, answers, screenshots, private documents, custom prompts, custom endpoints, or clipboard contents.

## Command Ideas

Use the command request template for new commands or search aliases.

Include the input, output, search words, and privacy limits.

## Security

Read [SECURITY.md](SECURITY.md) before reporting private data, API key, clipboard, or permission problems.
