# Security

Fluid Reader handles selected text, screenshots, clipboard text, and API keys. Please report security or privacy problems with care.

## Report a Problem

Do not open a public issue for secrets, private text, screenshots, or API keys.

GitHub private vulnerability reporting is enabled for this repository. Use the repository Security tab if you want to report a vulnerability privately through GitHub.

If you cannot use that path, email the maintainer, or open a short public issue that says you found a security problem and can share details privately.

## What to Include

- What happened
- What you expected
- App version or commit
- macOS version
- Steps to reproduce
- Safe logs from `Copy Issue Bundle`, if they do not include private data

Do not send API keys, selected text, answers, screenshots, private documents, custom prompts, custom endpoints, or clipboard contents unless the maintainer asks and you are sure it is safe.

## Local Data

Fluid Reader stores local settings and optional history on your Mac. Use `Clear Local Reader Data` in Commands to clear reader text, answers, images, recent items, snippets, quick links, clipboard history, command learning, and the activity log.

## Supported Versions

Security fixes target the latest `main` branch.
