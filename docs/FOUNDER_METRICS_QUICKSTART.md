# Founder Metrics Quickstart

Use Commands (`Option + Shift + Space`) for fast startup math you can paste into docs, investor updates, and team chats.

## Core Inputs

Keep a small note with these numbers:

- Monthly recurring revenue
- Cost of goods sold or service delivery cost
- Sales + marketing spend
- New customers in period
- Monthly contribution per customer
- Expected lifetime in months

## Useful Formulas

Type these directly in Commands:

- `roi 1200 1000` → return on investment
- `margin 100 75` → gross margin
- `markup 125 100` → markup on cost
- `cagr 100 121 2` → compound annual growth rate
- `breakeven 10000 50 30` → break-even unit count
- `runway 240000 12000` → months of runway at current burn
- `payback 900 75` → CAC payback period (months)
- `ltvcac 1350 150` → LTV/CAC ratio
- `burnmultiple 120000 240000` → burn multiple (net burn / net new ARR)
- `nrr 1000 200 100 50` → net revenue retention %
- `quickratio 120 30 50 10` → SaaS quick ratio
- `magicnumber 250000 400000` → SaaS magic number
- `rule40 35 10` → rule of 40 score
- `ltv 75 18` → customer lifetime value
- `cac 12000 80` → customer acquisition cost

Natural aliases work too, for example: `gross margin 100 75`, `break even 10000 50 30`, `runway months 240000 12000`, `cac payback 900 75`, `payback period 900 75`, `ltv/cac 1350 150`, `burn multiple 120000 240000`, `net revenue retention 1000 200 100 50`, `quick ratio 120 30 50 10`, `magic number 250000 400000`, and `rule of 40 35 10`.

If you want the full weekly command stack in one shot, run `Copy Founder Command Presets` from Commands.

## Daily Founder Flow

1. Open Commands and run your KPI formulas.
2. Paste outputs into standup notes or weekly updates.
3. Re-run the same commands after new data arrives.
4. Track trend changes (for example, `ltv` up while `cac` down).

Tip: Add this doc to your weekly ritual so metrics stay consistent across the team.
