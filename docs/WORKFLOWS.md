# Workflows

Use these short flows to get value fast.

For the best first commands to try, see [POWER_USER_GUIDE.md](POWER_USER_GUIDE.md).

## Read And Save

For text from any app:

1. Select text.
2. Open Commands.
3. Run `Read Selected Text`.
4. Run `Copy Selected as Quote`.
5. Run `Save Selected as Snippet`.

Search `snippet` later to copy, paste, pin, or delete the saved text.

## Clean Links

For links in notes, issues, or chat:

1. Select a URL.
2. Run `Copy Selected Clean URL` if it has tracking params.
3. Run `Copy Selected URL as Markdown Link`.
4. Or run `Copy Selected URLs` when the text has many links.
5. Run `Copy Selected Domains` when you only need host names.

For copied links, run `Clean URL Clipboard` to remove tracking params.

## Triage A Bug

For a bug report:

1. Run `Copy Issue Bundle`.
2. Paste it into the issue.
3. Add only the private details the project needs.
4. Run `Copy Activity Log` if the bug is hard to explain.

Support commands skip API keys, selected text, answers, images, snippets, quick links, clipboard history, custom prompts, custom endpoints, and clipboard contents.

## Write Faster

For notes, docs, or replies:

1. Select rough text.
2. Run `Copy Selected as Bullets` or `Copy Selected as Numbered List`.
3. Run `Copy Selected Text Stats` for quick length checks.
4. If LLM is on, run `Rewrite`, `Reply Draft`, or `Action Items`.

## Developer Scratchpad

For small dev tasks:

1. Type `2 + 3 * 4` to copy a math result.
2. Type `10 km to miles` to copy a unit conversion.
3. Type `09:00 UTC to local`, `09:15 UTC+5:30 to UTC-4`, or `9 pm PST to EST` to copy a time conversion.
4. Type `in 3 days`, `next monday`, `end of month`, or `2 weeks from now` to copy a date result.
5. Type `#ff8800` to copy color formats.
6. Select JSON and run `Copy Selected Pretty JSON` or `Copy Selected Minified JSON`.
7. Select text and run `Copy Selected Slug`, `Copy Selected Snake Case`, `Copy Selected Constant Case`, `Copy Selected Camel Case`, or `Copy Selected Pascal Case`.
8. Select text and run `Base64 Encode Selected` or `Base64 Decode Selected`.
9. Select terminal logs and run `Remove Terminal Colors Selected`.
10. Select messy text and run `Single Space Selected`, `Uppercase Selected`, `Lowercase Selected`, or `Title Case Selected`.
11. Select lines and run `Join Selected Lines`, `Reverse Selected Lines`, `Sort Selected Lines`, or `Unique Selected Lines`.
12. Select CSV or TSV and run `Markdown Table Selected` or `Clean CSV Selected`.
13. Run `Pretty JSON Clipboard`, `Slugify Clipboard`, or `Remove Terminal Colors Clipboard`.

## Window Work

For quick layout:

1. Open the app you want to move.
2. Open Commands.
3. Run `Window Left Half`, `Window Right Half`, `Window Maximize`, or `Window Center`.

Window commands need Accessibility permission.

## Demo Path

Use this for a fast live demo:

1. Select text and run `Read Selected Text`.
2. Type `sqrt(81)`.
3. Type `8 fl oz to ml`.
4. Type `14:30 UTC+8 to UTC`.
5. Select a paragraph with links and run `Copy Selected Domains`.
6. Run `Copy Issue Bundle` and point out that private reader content is skipped.
