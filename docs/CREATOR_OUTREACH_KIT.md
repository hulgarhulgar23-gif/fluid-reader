# Creator Outreach Kit

Use this kit to turn one launch-week proof into creator, community, and podcast outreach quickly.

Generate a first draft with:

```sh
zsh scripts/generate_creator_outreach_kit.sh --out docs/campaigns/$(date +%Y-W%V)-creator-outreach.md
```

The generated kit includes:

- Positioning summary from one real workflow result.
- Three DM drafts for creators/newsletters/video channels.
- A podcast/interview pitch draft.
- A community moderator pitch draft.
- A partner tracker table.
- A 7-day follow-up cadence.
- CTA split-test options.

## Suggested Weekly Use

1. Generate the outreach kit on launch day.
2. Send 5 focused outreach messages on Day 0.
3. Follow up with top prospects on Days 2 and 4.
4. Convert one accepted collaboration into next week’s proof asset.
5. Log `Creator outreach sent/replies/collaborations/cross-posts` in `Monday Publish Checklist <week>`.
6. Add/update a `weekly-growth-creator-signal` comment for each high-value handle touched.
7. Check Friday channel ROI recommendation before choosing Monday lead channel.
8. Reuse the generated distribution follow-up plan to schedule Days 2 to 7 outreach touchpoints.
9. Set audience regions on manual Friday review runs so Monday windows match where replies are expected.
