# Social Proof Kit

Use these templates to turn real Fluid Reader usage into posts quickly.
You can auto-generate a first draft with:

```sh
zsh scripts/generate_social_proof_kit.sh --out docs/campaigns/$(date +%Y-W%V)-social-proof.md
```

Use [WEEKLY_POST_PLANNER.md](WEEKLY_POST_PLANNER.md) to schedule these formats.
Use [DISTRIBUTION_PLAYBOOK.md](DISTRIBUTION_PLAYBOOK.md) to adapt one proof across channels.
Use [CAMPAIGN_AUTOMATION.md](CAMPAIGN_AUTOMATION.md) to generate first drafts quickly.

## Quick Rules

- Keep every post tied to one real task.
- Show one command name in each post.
- Prefer short clips or one clean screenshot.
- End with one clear call to action.

## Post Formats

### 1) Before / After

```
Before: manual copy/paste + cleanup.
After: one shortcut + one command.

Today I used Fluid Reader:
- Option + Shift + Space
- Read Selected Text
- Copy Win Card

Saved me ~X minutes on [task].
```

### 2) 3-Step Workflow

```
Tiny workflow I now use daily:
1) Read Selected Text
2) Ask Anything
3) Copy Win Recap

That turns [input] into [output] in under a minute.
```

### 3) Command Spotlight

```
Command spotlight: Copy Win Card

I use it after finishing a focused session.
It creates a share-ready visual recap from local usage counts.
```

### 4) “I Replaced X” Post

```
I replaced [old workflow/tool step] with:
- Option + Shift + Space
- [one command]

The win: [speed/quality/reliability].
```

## Channel Variants

### X / Threads

- Use 1 short hook.
- Keep to 3 to 5 lines.
- Add one screenshot or one Win Card image.

### LinkedIn

- Use context + problem + outcome.
- Include one practical example from work.
- End with one discussion prompt.

### Reddit / Hacker News comments

- Skip hype.
- Explain exact workflow and commands.
- Share one caveat and one measured gain.

## 10 Ready Hooks

- “I turned a 5-minute task into 45 seconds.”
- “One shortcut I now use every hour.”
- “Small app, big daily leverage.”
- “Command palette + OCR is a ridiculous combo.”
- “This is my fastest way to summarize selected text.”
- “I finally have a shareable end-of-session recap.”
- “This replaced my copy/paste cleanup loop.”
- “A practical LLM workflow I can run in seconds.”
- “Setup took under a minute; payoff is daily.”
- “My new default for quick reading + asking.”

## CTA Bank

- “Try this flow and tell me your use case.”
- “What command would you add next?”
- “Want my exact 60-second setup steps?”
- “Reply with your workflow and I’ll suggest commands.”
- “If this helps, share your first Win Card.”

## Weekly Cadence

- Monday: before/after.
- Wednesday: command spotlight.
- Friday: workflow thread + Win Card.

## Asset Checklist

- One clean screenshot or Win Card.
- One short clip (15 to 45 seconds).
- One line of measurable outcome.
- One command list viewers can copy.

## Safety + Privacy

- Do not post private selected text.
- Use support-safe exports when sharing diagnostics.
- Prefer example content in demos.
