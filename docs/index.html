Fluid Reader

Draw around anything on your screen and hear it read aloud. A small, local-first menu-bar app for macOS.

Download for macOS View on GitHub
brew install --cask hulgarhulgar23-gif/fluidreader/fluid-reader

macOS 14+ · Apple Silicon · MIT licensed · ~1.4 MB download

What it does

●Read anything on screen

Press ⌥⇧R, draw around any content — a PDF, an image, a video frame — and Fluid Reader OCRs it with Apple Vision and reads it with macOS voices.

●Keyboard-first commands

Press ⌥⇧Space for a command palette: read selection, snippets, clipboard tools, quick conversions, an inline calculator, and more.

●Optional LLM, off by default

Ask questions about selected content with your own API key. The app is fully useful without one — LLM support stays off until you turn it on.

●Tiny and native

A single ~3 MB app bundle. No Electron, no account, no telemetry, no background network requests. Updates are checked only when you ask.

Private by default

  • Screen captures never leave your Mac.
  • OCR runs on-device with Apple Vision.
  • Speech uses the built-in macOS voices.
  • No analytics, no account, no auto-networking.
  • Support bundles exclude private reader content by default.
  • Open source under the MIT license — audit everything.

Shortcuts

⌥⇧SpaceOpen Commands palette
⌥⇧RPick and Read — draw around screen content
⌥⇧LLaunch Recovery Next (during onboarding recovery)
⌘ ,Settings (from the menu-bar menu)

Install

Download the latest release, unzip, and move FluidReader.app to Applications. Current builds are not notarized yet: the first time, right-click the app, choose Open, then click Open again. Grant Screen Recording and Accessibility permissions when macOS asks.
