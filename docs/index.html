One local launcher for your Mac.
Read, ask, note, script, tile.

Fluid Reader is a local-first menu-bar launcher for macOS. Press ⌥⇧Space by default to search apps, files, notes, AI commands, scripts, and window actions from one bar — then use ⌥⇧R by default when screen content needs OCR and read-aloud. Nothing leaves your Mac by default.

How it works

One bar for launch, one hotkey for OCR

Press ⌥⇧Space by default

From anywhere. Search apps, files, notes, quick links, clipboard history, AI commands, scripts, and window actions from one launcher.

Run or refine

Use custom aliases, global hotkeys, Compact Mode, and the Action Panel to turn the same launcher into your personal command surface.

Pick when copy fails

Need text from a screenshot, PDF, paused video, or inaccessible app? Press ⌥⇧R by default and Fluid Reader falls back to on-device OCR and read-aloud.

Command palette

Keyboard-first, for everything else

Press ⌥⇧Space by default for one root search: launch apps, open indexed files from your configured folders (Desktop, Documents, and Downloads by default), open common folders, restore recent reader items, reuse saved snippets, open saved quick links, and revisit clipboard history while reading the current selection, and run quick unit/date conversions or the inline calculator.

Want more? Bring your own API key and ask questions about whatever you've selected. LLM support is off by default — the app is fully useful without it.

Need the launcher to choose for you? Run Best Local Action routes a plain-English request to the best local AI Command or Script Command, and the same flow is available from root search with route: or do:.

The default list stays focused on launcher hubs and the core reader flow, with current-text and answer actions only appearing when they are actually ready, but typing, scoping a category, or adding your own aliases, global hotkeys, and indexed roots in Settings lets you reach the broader command catalog fast.

When the launcher is idle, it now also acts like a small launcher home with quick tiles for Pick and Read, Screenshot, Ask, Route Request, Notes, Extensions, Windows, and Setup, plus compact platform chips for Reader, Refresh Search, Hide/Show Menu Bar, and Settings.

Press ⌘K on the selected result to open the Action Panel for contextual launcher actions like reveal, copy path, copy link, or favorite.

Prefer a tighter launcher? Turn on Compact launcher mode in Settings to shrink the window, rows, footer, and Action Panel without losing any commands.

When the launcher is idle, it now also shows a compact root-search summary with live source counts and one-tap scope chips like app:, file:, note:, clip:, route:, and tile: so the one-bar search model stays obvious without extra clutter.

Need automation too? Drop shell, Python, Node, Ruby, Swift, PHP, or PowerShell scripts into ~/Library/Application Support/FluidReader/ScriptCommands. They show up in the same launcher and support the same aliases, global hotkeys, and Action Panel flow as built-in commands.

Launcher tuning stays cleaner too: Settings → Launcher now shows quick customization counts plus focused filters for customized commands, platform actions, AI, windows, scripts, or the full catalog, so aliases and hotkeys do not feel buried in one giant list.

Personal workspace is built in too: saved snippets now double as local notes, and Open Notes Workspace gives you one place to search, edit, pin, copy, and reopen them.

Notes and extensions stay tidy too: each workspace now shows quick counts and focused filters, so saved notes, AI commands, local scripts, and starter installs feel like a real platform surface rather than one long utility list.

Want a local extension surface? Open Extensions Workspace groups AI Commands, installable starter extensions, importable local extension packs, and Script Commands into one hub, while Window Settings now previews the active cycle, keeps saved layouts and gaps together, and exposes direct window-action hotkeys in the same platform story.

Why it's different

Small, native, honest

One launcher, many surfaces

Root search, aliases, hotkeys, Action Panel, notes, scripts, AI commands, quick links, clipboard history, files, and apps all stay in one keyboard-first flow.

OCR when other launchers stop

Scanned PDFs, screenshots, paused videos, and apps with no accessibility support still work because OCR and read-aloud are part of the launcher, not bolted on later.

Tiny and native

A single app bundle of a few megabytes. No Electron, no account, no telemetry. Updates are checked only when you ask.

Local-first by default

Uses the macOS voices and on-device OCR you already have. AI is opt-in with your own key, and support bundles skip private reader content by default.

Private by default

Local-first is the whole point

  • Screen captures never leave your Mac.
  • OCR runs on-device with Apple Vision.
  • Speech uses the built-in macOS voices.
  • No analytics, no account, no auto-networking.
  • LLM features are opt-in and use your own key.
  • Support bundles exclude private reader content by default.

Install

Up and running in a minute

  1. Download the latest release and unzip it.
  2. Move FluidReader.app to Applications.
  3. Grant Screen Recording and Accessibility permissions when macOS asks.

Builds aren't notarized yet: the first time, right-click the app and choose Open, then click Open again.
