# Weekly Post Planner

Use this sheet each week to turn real Fluid Reader usage into a repeatable posting plan.

Pair this with [LAUNCH_PLAYBOOK.md](LAUNCH_PLAYBOOK.md) and [SOCIAL_PROOF_KIT.md](SOCIAL_PROOF_KIT.md).

## 20-Minute Weekly Setup

0. Run `zsh scripts/generate_campaign_pack.sh --out docs/campaigns/$(date +%Y-W%V).md`.
1. Pick one practical workflow from [WORKFLOWS.md](WORKFLOWS.md).
2. Generate fresh proof in-app:
   - `Copy Win Card`
   - `Copy Win Recap`
   - `Copy Win Recap Pack`
3. Choose one measurable outcome to repeat all week.
4. Fill the planner table below.

## Planner Template

| Day | Theme | Command Proof | Draft Hook | CTA | Status |
| --- | --- | --- | --- | --- | --- |
| Monday | Before / After | `Copy Win Card` | “I replaced X with one command.” | “Want the exact flow?” | Draft |
| Wednesday | Command Spotlight | `Copy Win Recap` | “Command spotlight: [command name]” | “What should I test next?” | Draft |
| Friday | Workflow Thread | `Copy Win Recap Pack` | “3-step workflow I now use daily” | “Share your version; I’ll suggest tweaks.” | Draft |

## Copy-Paste Draft Blocks

### Monday: Before / After

```text
Before: [old manual loop]
After: Option + Shift + Space + [command]

Output changed from [before state] to [after state] in [time].
```

### Wednesday: Command Spotlight

```text
Command spotlight: [command]

I use it for [task].
This week it helped me [measurable outcome].
```

### Friday: Workflow Thread

```text
Tiny workflow:
1) [command]
2) [command]
3) [command]

Result: [outcome] in under [time].
```
